# Drunken Guide

Многостраничный адаптивный сайт о напитках: тёмная палитра, золотые акценты и фотографии коктейлей. Обычные HTML-переходы, без диалоговых окон.

## Запуск

Установка зависимостей и сборка не нужны. Из корня репозитория:

```sh
python3 -m http.server 8000 --bind 0.0.0.0
```

## Страницы

- `index.html` — главная.
- `catalog.html` — пять коктейлей, поиск по названию и ингредиентам, фильтры по основе и вкусу.
- `recipe-*.html` — пять отдельных рецептов с ингредиентами и пошаговым приготовлением.
- `collections.html`, `collection-*.html` — три тематические подборки.
- `drinks.html` — справочник по категориям напитков.
- `favorites.html` — рецепты, сохранённые в localStorage этого браузера.
- `about.html` — проект и описание запланированных функций.
- `download.html` — информация о будущем приложении; ссылки на магазины пока не доступны.

Переходы, рецепты и описания работают без JavaScript; поиск, меню на мобильном экране и избранное используют `script.js`. Избранное не синхронизируется между устройствами. Пользовательские аккаунты, общие отзывы и серверная часть не реализованы.

Сайт публикуется GitHub Pages из корня ветки `main`. Все ссылки относительные и поддерживают путь `/sitealco1/`.

Изображения `assets/cocktail-bar.png` и `assets/drink-collection.png` сгенерированы для проекта. Фотографии внутри общего изображения отображаются через SVG с сохранением пропорций. Шрифты Manrope и Cormorant Garamond с кириллицей хранятся в `assets/fonts/`; лицензии OFL приложены. Значки магазинов — встроенные SVG. Внешние сервисы и API не нужны.
