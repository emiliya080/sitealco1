# Drunken Guide

Адаптивный сайт о напитках и коктейлях по визуальному образцу: тёмная палитра, золотые акценты, макеты приложения и тематические подборки.

## Запуск

Зависимости и сборка не требуются. Из каталога репозитория:

```sh
python3 -m http.server 8000 --bind 0.0.0.0
```

Откройте сайт на порту 8000. Также можно открыть `index.html` напрямую. Для сохранения избранного рекомендуется HTTP-сервер; используется localStorage браузера.

Карточки открывают рецепты, кнопка сердца сохраняет избранное, мобильное меню ведёт к разделам. Кнопки App Store и Google Play открывают уведомление: приложение пока не опубликовано.

Изображение `assets/cocktail-bar.png` сгенерировано для проекта. Внешние шрифты, сервисы и API не нужны.
