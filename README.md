# Drunken Guide

Многостраничная платформа о напитках в чёрно-золотом оформлении. Фотографическое оформление с плавным движением камеры, полупрозрачные страницы рецептов и обычная навигация без диалоговых окон.

## Два режима работы

### Статический сайт / GitHub Pages

Без установки зависимостей:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Откройте корень сайта на порту 8000. Работают: поиск и расширенные фильтры, подбор по девяти поводам, сравнение до четырёх рецептов, планировщик вечеринки с общим списком покупок, собственные рецепты, домашний бар, избранное и сохранение на этом устройстве. Конфигурация `site-config.js` явно отключает серверные аккаунты; пароли в localStorage не хранятся.

### Серверная версия

```sh
python3 -m venv .venv
.venv/bin/pip install -r server/requirements.txt
APP_ENV=development APP_ORIGIN=http://127.0.0.1:8001 .venv/bin/python server/app.py serve
```

Откройте корень на 127.0.0.1:8001. Добавляются реальные аккаунты и сессии, профиль/аватар, сохранение и восстановление коллекций из SQLite, отзывы с фото, рейтинг из опубликованных оценок, отправка авторских рецептов на модерацию и админка. Сервер сам предоставляет `site-config.js` с API того же домена.

Первый администратор создаётся из терминала с безопасным скрытым вводом пароля:

```sh
.venv/bin/python server/app.py create-admin --email admin@example.com --name Администратор
```

Не публикуйте `.env`, базу SQLite или реальные пароли. Они исключены из Git. Схема SQLite создаётся автоматически, существующие записи при перезапуске не удаляются. Данные в `var/` либо `APP_DB` нужно резервировать.

Размещение в Docker, HTTPS-прокси и ограничения: [server/DEPLOY.md](server/DEPLOY.md). Production требует HTTPS-домен `APP_ORIGIN`; cookies HttpOnly/SameSite и Secure. Проверки роли, авторства отзывов, загрузок, сессий и источника запросов выполняются сервером.

## Разделы

- `index.html` — главная, инструменты и популярные рецепты.
- `catalog.html`, `mocktails.html` — алкогольные и безалкогольные рецепты.
- `occasions.html` — подбор по поводу и гостям.
- `recipe-*.html` — рецепты; `recipe.html?id=...` — новые рецепты, добавленные администратором.
- `compare.html` — таблица характеристик и общих/уникальных ингредиентов.
- `planner.html` — порции, домашние запасы, общий список, ручные правки, отметки покупок, сохранение планов со списками, копирование и ссылка на план.
- `builder.html?mode=create` — собственные рецепты и расчёт объёма/крепости.
- `builder.html?mode=preferences` — подбор по предпочтениям.
- `builder.html?mode=bar` — домашний бар и три группы доступности.
- `encyclopedia.html`, `encyclopedia-*.html` — 11 категорий напитков; новые категории доступны через `encyclopedia.html?category=...`.
- `account.html`, `admin.html` — аккаунт и серверное управление.
- `help.html`, `privacy.html`, `terms.html`, `about.html`, `download.html` — справка и информация.

Каталог/ингредиенты/поводы/энциклопедия: `content/platform-data.json`. Общие чистые расчёты: `platform-core.js`. Интерфейс: `platform.js`. Анимация главной: `photo-home.js` (вступление) и `home-story.js` (сцены по всей странице). Предпочтение уменьшенного движения учитывается.

## Текущее наполнение и ограничения

- Исходный каталог: **5 алкогольных + 3 безалкогольных** рецепта. План `content/COCKTAILS-100.md` ещё не равен готовой опубликованной базе.
- Оформление состоит из 19 локальных фотокомпозиций без людей. Первые две сцены — обработанные фотографии пользователя; ещё у двух кадров очищен фон генеративным редактором. Их реальные мастера 1672×941 и 1024×1536 не выдаются за 4K. Для остальных снимков подготовлены версии до 3840px без увеличения оригинала. Размеры, авторство, лицензии и характер обработки опубликованы в `photos.html` и `content/photo-manifest.json`. Подробности: `content/PHOTO-SOURCES.md`.
- Расчёт крепости — по типовым крепостям ингредиентов, до разбавления талым льдом. Это приближённое значение, не лабораторное измерение.
- Замены ограничены вариантами, внесёнными в конкретный рецепт, с объяснением изменения вкуса и крепости. Автоматически случайные замены не подбираются.
- Отправка email, восстановление пароля, подтверждение почты, уведомления, Google/Apple OAuth и нативные приложения пока не подключены. Интерфейс не обещает их доступность.
- Локальные изменения сохраняются в аккаунте по явной кнопке. Загрузка аккаунта требует подтверждения, чтобы не затереть данные устройства без предупреждения.
- Документы — информационные заготовки с явной пометкой. Перед публичным запуском аккаунтов нужны сведения оператора и юридическая проверка для целевых стран.

## Проверки

```sh
node tests/core.test.cjs
python3 -m unittest discover -s tests -p 'test_*.py'
```

Тесты используют временную БД и фиктивные учётные записи. Покрывают расчёты, сессии, изоляцию аккаунтов, модерацию, права доступа, загрузки изображений, сохранность данных, авторские рецепты и валидацию каталога. Дополнительно проверены сценарии в Chromium для статической и серверной версий, включая мобильные размеры.

Шрифты Manrope и Cormorant Garamond хранятся локально в `assets/fonts/`; лицензии OFL приложены. Внешние сервисы для локальных инструментов не требуются.

## Главная со scrollytelling

Главная разворачивается от полноэкранного фото-вступления к приготовлению Negroni, четырём карточкам классики с дозировками, клюквенному спритцу, подборкам по настроению, энциклопедии, трём рецептам без алкоголя и шести локальным инструментам. Карточки и фотографии ведут на существующие страницы. Макеты телефонов, видео и сгенерированные объекты на главной не используются. Фотографии вариантов подачи снабжены поясняющими подписями. В безалкогольном разделе есть основной снимок и отдельные миниатюры всех трёх рецептов. В финале и общем подвале разные фотографии бокалов без людей. Фотографии разделов знаний и безалкогольных напитков заполняют весь фон.

Разные сцены используют растворение и приближение фотографий, подсветку шагов в закреплённом разделе, горизонтальное движение подборок, параллакс, раскрытие фотографии и появление карточек. Прокрутка остаётся нативной. На телефоне сложные закреплённые сцены заменяются вертикальным содержимым. При отключении анимации и prefers-reduced-motion весь контент остаётся доступен. Циклы requestAnimationFrame останавливаются после завершения движения.

Главная создаётся из локального каталога командой `python3 scripts/build_home.py`. Результат статический: рецепты и их ссылки доступны без JavaScript. Команда воспроизводима при повторном запуске. При изменении основных данных не забудьте пересобрать страницу. `python3 scripts/check_site_links.py` проверяет локальные страницы, ресурсы и якоря. `python3 scripts/build_photo_credits.py` собирает страницу авторства; `scripts/build_media.py` создаёт адаптивные файлы из оригиналов и обработанных мастеров без увеличения разрешения. `python3 scripts/sync_media_pages.py` синхронизирует статические страницы и версии ресурсов.

```sh
python3 -m http.server 8000 --bind 127.0.0.1
# В другом терминале:
STORY_TEST_BASE_URL=http://127.0.0.1:8000 node tests/photo-cinema.browser.cjs
STORY_TEST_BASE_URL=http://127.0.0.1:8000 node tests/home-journey.browser.cjs
STORY_TEST_BASE_URL=http://127.0.0.1:8000 node tests/photo-home.browser.cjs
STORY_TEST_BASE_URL=http://127.0.0.1:8000 node tests/site-pages.browser.cjs
```

Браузерные тесты покрывают переходы и обратную прокрутку, полную ширину 360–1440px, выбор наибольшего доступного исходного разрешения, рецепты/порции/избранное/сравнение/покупки, фильтры трёх подборок, статьи, отключение анимации, отказ внешних изображений и содержимое без JavaScript. Тесты используют реальные локальные изображения без подмены. Дополнительно обходятся все 42 HTML-страницы: проверяются отрисовка содержания, все изображения, сформированные ссылки и отсутствие внешних запросов фотографий. `tests/test_photos.py` проверяет реальное разрешение WebP и метаданные авторства. Источники и лицензии описаны отдельно.
